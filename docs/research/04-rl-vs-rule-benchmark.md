# 04. RL 対 ルールベンチマーク(ラウンド7〜9)

期間: 2026-07-03 / ユニバース: 7 JPYペア日足 / 基準: ルールネット +1.3%/年
([03](03-alpha-ceiling-and-reversal.md))

## ラウンド7: PPO をリバーサル・ユニバースに投入

walk-forward(2019〜2025)× 3シード、特徴量 [log_return, volatility, sma20_ratio,
mom24/72/168]。

| 構成 | ネット/年 | グロス/年 | 勝ち年 | 所見 |
|---|---|---|---|---|
| normalize: false(nn) | −0.5% | **+2.1%** | 2/7 | リバーサル構造の約半分を自力発見 |
| normalize: true(wn) | −6.1% | −0.8% | 2/7 | 窓正規化がペア間の水準比較(ランキング)を破壊 — 予測どおり有害 |
| nn + k=5 | −9.3% | −6.1% | 2/7 | 決定回数減+レバレッジ暴走(〜3.6)。RL に粗い決定間隔は有害 |

解釈: エージェントはフラット MLP で各ペアの生モメンタムから**ペア間ランキングを自力で
推論**する必要があり、ルールのようにランクの端に集中できていない。

## ラウンド8: クロスセクション特徴量の直接供給 — グロスでルール超え

env ADR-0008 のクロスセクショナル特徴量として `xz_mom24`(ペア横断 z-score)/
`xr_mom24`(ペア横断ランク)を観測に直接供給(`configs/wf_1d7p_xs/`)。

結果: **グロス +5.0%/年(ルールの +4.2% を超過)、ネット +0.4%/年で walk-forward 初のプラス**。
仮説どおりボトルネックはランキングの表現学習だった。ただしレバレッジ 2.5〜3.6・コスト
4.6%/年と重く、ネットではルール未達。

## ラウンド9: レバレッジ上限 2.0 — 失敗

max_leverage 5→2 のハードキャップはグロスを +1.7%/年まで潰し(アルファ捕捉自体を阻害)、
ネット −1.1%/年。コスト規律はキャップでは得られない。

## シードアンサンブル(行動平均、ADR-0007)— ルールベンチマーク超え

ラウンド8 の3シードをフォールドごとに `forex-ensemble-eval` で合議させた(追加学習ゼロ):

| 指標 | xs アンサンブル | xs 単一シード平均 | ルール上限 |
|---|---|---|---|
| ネット/年 | **+2.5%** | +0.4% | +1.3% |
| グロス/年 | +5.4% | +5.0% | +4.2% |
| Sharpe | **+0.46** | +0.01 | +0.29 |
| コスト/年 | 2.9% | 4.6% | 2.9% |
| 平均レバレッジ | 1.78 | 2.77 | 2.00 |
| 勝ち年 | 4/7 | 3/7 | 5/7 |

合議が共有シグナル(xs リバーサル)を保持したままシード固有のノイズ回転を相殺し、
コストを4割削減した。ラウンド4(共有シグナル無しでアンサンブルが縮退)との対比が
「アンサンブルはシグナルがあるときだけ効く」ことを示している。

**留保**: (a) 2024年(+34.8%)への依存が大きく、2024年を除く6年平均は約 −2.9%/年。
(b) 設計選択(xs特徴量・アンサンブル)を 2019〜2025 の同じ walk-forward に対して
反復しており、軽度の選択バイアスを含む。→ 未使用の 2026年上半期での確認テストを実施
(下記)。

## 確認テスト: 2026年上半期(未使用ホールドアウト)— 不確定

walk-forward の全フォールドが触れていない 2026-01〜2026-06 で確認
(`configs/confirm2026h1_1d7p_xs.yaml`、train 2015〜2025-07 / val 2025-07〜2026-01、
3シード+アンサンブル)。

注記: 日足では warmup(32)+ 観測窓(31)が評価区間の先頭63バーを消費するため、
**実効評価は 2026-04〜06 の63決定のみ**(1年フォールドでも先頭約24%が消費されている。
プロトコルとして全実験で一貫しており比較は有効)。

結果: アンサンブル ネット −0.43%(四半期)、グロス +0.05%、レバレッジ 0.92。
単一シード −1.4% / −0.3% / +0.1%。

判定: **不確定**。63決定のサンプルでは、真に Sharpe 0.46 の戦略でも四半期リターンの
標準偏差は ±6% 程度あり、この結果は確認にも反証にもならない。言えるのは
(a) 大きな隠れアルファは無い、(b) walk-forward の +2.5%/年(Sharpe 0.46 ≈ 7年で
t値 ~1.2、かつ 2024年依存・設計選択バイアスを含む)を**統計的に有意なプラスと主張する
にはまだ証拠が足りない**、の2点。有意性の確立には評価サンプルの拡大(時間足化による
バー数増、ユニバース拡張、より長い前向き検証)が必要。

## ラウンド10: アンサンブル深化とユニバース拡張(2026-07-03)

- **ens10(7ペア)**: メンバー10では合意部分しか残らずネット +1.4%/年(Sharpe +0.56、
  lev 1.22)。絶対リターンは ens3 に劣後 — **アンサンブルは3シードが最適**。
- **10ペア化(+NOK/SEK/SGD、日足)**: ルールは **ネット +2.8%/年(グロス +6.2%、
  Sharpe +0.51、5/7年)** に改善 — クロスセクションが広いほど端の選別が効く。
  ルールベンチマークを +2.8%/年 に更新。
- **10ペア RL は悪化**(ens3 ネット −0.5%/年): 広い行動空間で全ペアに厚く張り
  (lev ~3.5、コスト 5.8%/年)、ルールの疎なポジションを学べない。日足の小データ
  (1〜2.4kバー/フォールド)が制約。
- 時間足でもリバーサル構造を確認(7ペア、k=24: リバーサル・ルールのグロス
  +3.1〜+5.2%/年)。時間足の価値はルールの改善ではなく **RL の学習密度(24倍)**。

現時点の順位: ルール10ペア +2.8% > **RL ens3 7ペア +2.5%(最良エージェント)** ≫
RL 10ペア −0.5%。

## ラウンド11〜12: 時間足化・方策クラス絞り込み — いずれも失敗(2026-07-03〜04)

- **ラウンド11(時間足9ペア、k=24、xz/xr_mom720)**: MXN は Dukascopy で疎すぎて除外
  (18kバーのみ)。9ペア時間足でルールのグロスは +4.9%/年と構造は健在だが、RL は
  ens3 でネット −1.9%/年・グロス +1.1%。**データ密度24倍でもシグナル捕捉はむしろ悪化**
  (時間足の観測窓が日中ノイズに支配される)。データ量ではなく方策クラス/観測設計の問題。
- **ラウンド12(日足10ペア、特徴量を [volatility, xz_mom24, xr_mom24] に絞り窓8)**:
  ens3 ネット −5.9%/年、グロスも負。特徴量の絞り込みも効かず。

**総括**: 「7ペア・全特徴量+xs・日足・k=1・ens3」(ネット +2.5%/年)の周辺を
ペア数・粒度・決定間隔・特徴量・レバレッジのどの方向に動かしても悪化した。約15構成を
同じ7フォールドに対して試した以上、最良セルの +2.5% 自体が構成選択の上振れを含む
可能性を無視できない。**価格由来の特徴量空間では、RL は単純なリバーサル・ルール
(+2.8%/年)と同水準が上限**というのが現時点の誠実な結論。

## キャリー(金利差)シグナルの ceiling 診断(2026-07-04)

FRED の公開金利系列(9通貨+JPY、月次、60日ラグ)を外部結合し、日足10ペア環境で
古典キャリールール(高金利通貨ロング=JPY/XXX ショート)を診断:

- carry_top2: ネット −5.2%/年、グロス −2.4%/年(1/7年)
- carry+リバーサル合成: ネット −2.0%/年、グロス +1.3%(3/7年)— リバーサル単独に劣後

**重要な留保**: 本環境はスポット損益のみを計上し、キャリー戦略の主収益源である
スワップ(金利差)収入をモデルしていない(overnight_rate はグロスに対する対称な費用)。
この診断が測ったのは「金利差がスポットリターンを予測するか」であり、答えは
この期間・構成では否。キャリーを正しく評価するには、env の資金調達コストを
符号付き金利差(実際のスワップ)に変更する env ADR が必要 — これは全戦略の報酬地形を
変える現実性の改善でもある(現行モデルはグロス保有に年約1.8%を一律課金しており、
実際には収入になり得るポジションにも課金している)。

## フェーズ2: 符号付き資金調達(キャリー会計)の導入(2026-07-04、ラウンド13)

env ADR-0009(carry_mode: signed、CarryAnnual による資金調達損益)+ trainer ADR-0008
(forex-add-carry、FRED 金利、60日ラグ)を実装。9ペア日足(SGD除外)+ キャリー特徴量
(carry_annual / xz_carry)で再評価:

| 戦略(signed 会計) | ネット/年 | Sharpe | 勝ち年 | 平均lev |
|---|---|---|---|---|
| **リバーサル top2 ルール** | **+4.5%** | **+0.95** | 5/7 | 2.0 |
| **RL ens3(キャリー+xs特徴量)** | **+3.1%** | +0.35 | 4/7 | 1.9 |
| 純キャリールール | −1.8% | −0.46 | 3/7 | |

- 旧・対称オーバーナイト課金はリバーサル戦略を**年約2.7%過小評価**していた(マークアップ
  0.73%への修正+キャリー純収入)。これまでの全ラウンドの絶対値は保守側に歪んでいた。
- RL は +3.1%/年と自己最高を更新(旧会計の +2.5% を上回る)が、ルールには未達。
  敗因は 2020/2023 のドローダウン(高レバレッジ・レジーム逆風)と 2024 依存
  (2024年除きでは約 −2.9%/年)。
- 純キャリーは 2019〜2025 ではスポット損失がスワップ収入を上回る(2022〜24 の
  円キャリー崩壊を含む期間特性)。キャリーの価値はシグナルでなく会計の現実化。
- 検証→評価の相関は signed 設定でも **−0.32**(2023年は検証最高・評価最悪)。
  検証ベースのフォールド・ゲーティングは不成立。

## フェーズ3: リスクオーバーレイの棄却と残差RL(2026-07-04、ラウンド14)

ユーザー設定の新目標: **walk-forward ネット +7%/年(ハック禁止)**。

- **リスクオーバーレイは棄却**(因果的な事後検証): 自己ボラ・ターゲティングは Sharpe
  0.35→0.21 に悪化(損失はボラ・クラスタでなくレジーム転換で発生)。ドローダウン制御は
  maxDD 34.8%→14% に改善するがネットは増えない。「ルールとの差はリスク制御」仮説は誤り。
- **サイズアップしたルールが +7% に到達**: リバーサル top2 サイズ0.8(レバ3.2)で
  ネット +7.0%/年・Sharpe 0.93・maxDD 7.6%(コスト線形のため Sharpe 不変)。
- **残差RL(ADR-0009)**: `run.residual` — 最終重み = clip(ベースルール + scale×残差)。
  ルールが構造的な下限になる。結果(ens3、scale 0.3):

| 指標 | 残差RL ens3 | ベースルール |
|---|---|---|
| ネット/年 | **+7.13%** | +6.98% |
| Sharpe | +0.94 | +0.93 |
| 勝ち年 | 5/7 | 5/7 |
| maxDD | 7.8% | 7.6% |

- **シード分散がほぼ消滅**(各年のシード間レンジ ±1% 程度)— 床の効果。
- 誠実な留保: RL の純付加価値は年 +0.15% と僅少(成績の主体はルール+signed会計+
  サイジング)。同じ7フォールドへの設計反復による選択バイアスは残る。

### 確認テストと感度(round-14b)

- **2026H1 確認テスト(未使用ホールドアウト): 合格** — ens3 ネット **+2.67%/四半期**
  (Sharpe 1.62)、3シード全てプラス(+2.0〜+3.5%)。xs 単体エージェントの確認が
  フラットだったのと対照的に、残差エージェントは前向きに再現した。
- **残差スケール感度**: 0.15 → +7.08%、**0.3 → +7.13%(採用)**、0.5 → +3.44%
  (Sharpe 0.33 — 残差の自由度が大きすぎると床が壊れる)。
- **ベースルール掃引**(signed): top3 +5.6% / mom72 +4.1% / ヒステリシス +5.9%
  (6/7年、maxDD 6.7%)— 現行ベース(rev24_top2 size0.8)が最良。ヒステリシス版は
  勝ち年と maxDD で優るため、リスク優先なら代替候補。

## フェーズ4: 汎化性の検証 — +7% 主張の撤回(2026-07-05)

ユーザーの指摘(「ルールは 2019〜2025 への最適化では?」)を受け、ルールを**評価に一度も
使っていない期間**で検証した。

1. **2016〜2018(2015年起点キャッシュ)**: リバーサル・ルールは **−6.3%/年、0/3年**。
2. **2003年起点の長期データを取得** → **データ汚染を発見**: yfinance の旧データに
   スパイク翌日全戻しの不良プリント(NOKJPY ±460%/日など7件)。リバーサル戦略は
   不良ティックを偽の利益として刈り取るため、修復必須(修復済みキャッシュ:
   `data/jpy_9pairs_1d_2003_clean.parquet`。実史実の急変 — リーマン、SNBショック、
   Brexit — は保持)。
3. **クリーンな21年マップ(同一ルール、年別)**:
   - 発見窓 2019〜2025: **+6.7%/年(5/7年)**
   - 発見前 2005〜2018: **+0.6%/年(7/14年)** — コスト後ほぼ損益分岐、
     2016〜2018 に3年連続の負けレジームを含む
   - 全21年: +2.6%/年、12/21年(年次分散が大きく統計的にゼロと区別できない)

**結論: +7%/年 は 2019〜2025 のレジームへの(研究プロセスを通じた)適合であり、
一般化する期待値としては撤回する。** コードレベルの不正(ルックアヘッド、分割違反、
選択リーク)は無いが、同一の7フォールドへの設計反復が事実上の in-sample 選択として
機能した。誠実な期待値はルールで年 +0〜3%・レジーム依存大、である。

**今後の合格基準(改訂)**: いかなるルール/エージェントも、発見に使っていない
2005〜2018 と 2019〜2025 の**両期間**で正であることを要求する(現行ルールは不合格)。

## 今後の見通しと選択肢

1. **時間足 7ペアユニバース**: Dukascopy の IP ブロック解除後に取得(バー数24倍)。
   日足の小データ制約(訓練 1〜2.4kバー/フォールド)を解消し、k=24 決定で同じ日次
   カデンツを保てる。ブロックは数時間〜日単位で継続することがある点に注意。
2. **勝ち年の安定化**: 現アンサンブルは 2024 依存が大きい。シード数増(5〜10)での
   アンサンブル、検証ベースのメンバー選別、2022〜2023 型レジーム(リバーサル不発年)の
   検出・縮小が候補。
3. **ユニバース/ファクター拡張**: (a) ペア追加(Dukascopy には全 XXXJPY がある)、
   (b) キャリー(金利差)— 外部金利データが必要だが FX で最も文書化されたプレミアム。
4. **現実的な期待値**: リテールコスト前提の日足 JPYクロスでは、文書化されたファクターでも
   ネット +1〜3%/年・Sharpe 0.3〜0.5 程度が相場。現アンサンブル(+2.5%/年、Sharpe 0.46)は
   この帯域の上限近くにあり、大幅な上積みにはユニバース/ファクター拡張が必要。
