## 今後の見通しと選択肢

1. **ラウンド8 の判定**(直近): xs 特徴量で RL がルールネット +1.3%/年を超えるか。
   超えない場合、RL の付加価値は当面「ルールのタイミング改善」には無いと判断する。
2. **時間足 7ペアユニバース**: Dukascopy の IP ブロック解除後に取得(バー数24倍)。
   日足の小データ制約(訓練 1〜2.4kバー/フォールド)を解消し、k=24 決定で同じ日次
   カデンツを保てる。ブロックは数時間〜日単位で継続することがある点に注意。
3. **ユニバース/ファクター拡張**: (a) ペア追加(Dukascopy には全 XXXJPY がある)、
   (b) キャリー(金利差)— 外部金利データが必要だが FX で最も文書化されたプレミアム。
4. **現実的な期待値**: リテールコスト前提の日足 JPYクロスでは、文書化されたファクターでも
   ネット +1〜3%/年・Sharpe 0.3〜0.5 程度が相場。「有意なプラス」の主張には複数年の
   walk-forward プラス(現基準)に加え、ユニバース拡張によるシャープの積み増しが必要。
