# 06. 外部データ拡張と独立ユニバースによる汎化性検証(フェーズ3)

期間: 2026-07-10〜20 / 目的: 「2019〜2025への期間適合ではなく、包括的に勝てるルール」の
追求(ユーザー指摘への応答)。特徴量エンジニアリング・外部データ・モデル構造探索・
独立サンプル拡大のどれが効くかを実証的に切り分ける。

## 実施内容

### 1. 外部データの実現可能性調査 → 実装

FRED(認証不要 CSV)で以下が取得可能と確認・実装した(`forex-add-factors` CLI):

- **10年国債金利差**(TermCarryAnnual): 短期金利より構造的なキャリー
- **相対PPP乖離**(PppGap): 実質為替レートの理論値からの乖離(CPI相対成長 vs 実勢レート)
- **グローバル系列**(VixLevel・OilLevel): 全ペア共通のリスク・商品指標

CFTC建玉(CoT)も取得可能と確認したが、対象9ペア中6ペアしかカバーしない
(NZD/NOK/SEKなし)ため今回は見送り(将来課題)。

### 2. 独立ユニバースの拡大 → env ADR-0010

env の基軸通貨制約(JPY専用の正規表現2箇所)を調査した結果、会計ロジック自体は
通貨に非依存と判明。`forex-env-v3` に **ADR-0010**(任意の基軸通貨、ただし同一環境内は
単一通貨に統一)を実装し、**USD建て9ペアの構造的に独立したユニバース**
(USD/JPY, EUR, GBP, AUD, CAD, CHF, NZD, NOK, SEK)を新規構築した。

- 2006年5月〜のyfinance日足を取得、不良プリント(スパイク翌日全戻し)7件を発見・修復
  (JPY/EUR 2008年10月・12月、NOK 2020年3月・2021年1月・2021年12月)
- 本物の歴史的イベント(2015年SNBのCHF固定相場撤廃)は修復アルゴリズムが正しく
  「非可逆」と判定し、手を加えていないことを確認済み
- `carry.py`・`factors.py` を通貨コード(3文字)キーに汎化し、どちらのユニバースにも
  同一コードで金利・CPI・キャリーを付与できるようにした

### 3. 新ファクターの ceiling 診断(RL投入前、両ユニバース・両時代)

| ルール | JPY 全体 | JPY era1/era2 | USD 全体 | USD era1/era2 |
|---|---|---|---|---|
| 10年金利差(順張り) | −2.7% | +0.5%/−7.1% | −0.1% | +0.0%/−0.3% |
| 10年金利差(逆張り) | −2.4% | −6.0%/+2.7% | −5.6% | −6.3%/−4.6% |
| PPP逆張り | −5.4% | −6.6%/−3.8% | −4.2% | −6.3%/−1.2% |
| PPP順張り | +0.3% | +1.5%/−1.3% | −0.7% | +1.1%/−3.2% |
| リバーサル(価格,参考) | +3.1% | +0.3%/+7.0% | +4.2% | +2.0%/+7.2% |
| リバーサル+金利差ブレンド | +1.6% | −2.1%/+6.8% | +0.5% | −1.5%/+3.3% |

**結論: 外部ファクターは単体で両時代・両ユニバースを通せるものがなく、価格リバーサルに
混ぜると悪化する。RL特徴量への採用を見送った**(規律どおり ceiling 不合格は投入しない)。
VIX条件付けのエクスポージャー抑制も追加検証したが、リターンを落とすのみ(過去のリスク
オーバーレイ検証と整合)。

### 4. 汎化性の核心テスト: 独立ユニバースでのルール再現

**最重要の発見**: 価格クロスセクション・リバーサル(mom24、ノーフィッティング)を、
設計に一切使っていない USD建てユニバースに適用したところ、**両時代で正**という結果を得た:

| ユニバース | 全体 | era1(2009-18) | era2(2019-25) |
|---|---|---|---|
| JPY建て | +3.1%/年(9/17) | +0.3%(4/10) | +7.0%(5/7) |
| **USD建て(独立)** | **+4.2%/年(10/17)** | **+2.0%(5/10)** | **+7.2%(5/7)** |
| momentum(符号反転,対照) | JPY −10.5% / USD −10.6% | 両ユニバースとも両時代で明確に負 | |

方向を反転させたモメンタムは両ユニバース・両時代で一貫して負。これは
「2019〜2025への期間適合」では説明できない、通貨基軸を丸ごと入れ替えても再現する構造
であり、この探索で得られた最も頑健な証拠である。

### 5. RL 本体の汎化テスト(ラウンド18)— 失敗

実証済みレシピ(`longf`: PPO+MLP, n_steps 1024, 300kステップ)をUSDユニバースの
17開発フォールドに適用:

| | JPY(既知) | **USD(新規)** |
|---|---|---|
| 全体 | +4.7%/年 | **−2.9%/年** |
| era1 | +6.7%(7/10) | **−6.6%(3/10)** |
| era2 | +1.8%(5/7) | +2.5%(4/7) |

**純RLはUSDユニバースへの汎化に失敗した**(ルール単体は+4.2%で正だったにもかかわらず)。
これは JPY での「学習成功」自体が汎化した技能ではなく、そのユニバース固有の適合だった
可能性を強く示唆する重要な負の結果である。

### 6. 残差RLの再検証(ラウンド19)— ユニバースにより結果が割れる

ラウンド14の残差RL(+7.13%/年)は「期間適合したルールの上に立っていた」ため撤回済み
だが、今回のルールは独立ユニバース検証済みであるため、同じ手法(残差スキーム、
ADR-0009、base_size 0.8・scale 0.3)を新しい17フォールド・両時代プロトコルで再検証した:

| | JPY 全体 | JPY era1/era2 | USD 全体 | USD era1/era2 |
|---|---|---|---|---|
| ルール床のみ | +3.1% | +0.3%/+7.0% | +4.2% | +2.0%/+7.2% |
| **残差RL(床+RL)** | **+4.4%** | **+3.1%/+6.2%** | **+3.1%** | **+0.1%/+7.4%** |
| 純RL(床なし) | +4.7% | +6.7%/+1.8% | −2.9% | −6.6%/+2.5% |

- **JPY**: 残差RLがルール単体を明確に上回る(+4.4% vs +3.1%、era1が+0.3%→+3.1%に改善)。
  両時代で正(margin あり)
- **USD**: 残差RLはルール単体を**下回る**(+3.1% vs +4.2%)。era1が+0.1%まで潰れ、
  「正」ではあるが実質横ばい(4/10年勝ち)。RLの寄与が正味でマイナスに働いた

**誠実な結論: 残差RLは普遍的に汎化する解法ではない。** JPYでは価値を生むが、USDでは
ルールの足を引っ張る。RLコンポーネントの効果はユニバース依存であり、「RLがルールを
一貫して改善する」という主張はできない。

## 全体総括(3フェーズを通じて)

1. **効いたもの**: 資金調達会計の現実化(env ADR-0009)、クロスセクション・リバーサルという
   ルールクラス自体(2ユニバース×2時代で検証済み、現時点で最も頑健な発見)
2. **効かなかったもの**: 新規外部ファクター(金利差・PPP)単体、VIX条件付け、
   ペア間attention、RecurrentPPO/TQC、そして**純RLのユニバース間汎化**
3. **ユニバース依存**: 残差RL(JPYでは有効、USDでは無効)
4. **モデル構造探索への回答**: 今回の追加探索(ペア間attention早期実装、残差RL)は
   「構造を変えれば伸びる」という仮説を支持しなかった。ボトルネックは一貫して
   構造ではなくデータ量(独立サンプル数)とタスクの本質的な低SN比だった

## 「包括的に勝てるルール」への現在地

- 検証に耐えたのは **シンプルな価格クロスセクション・リバーサル**(ノーフィッティング、
  2ユニバース×2時代、Sharpe 0.3〜0.5相当)のみ
- RL(純粋・残差いずれも)はこのルールを**一貫して上回れていない**。上回る場面
  (JPY残差RL)と下回る場面(USD純RL・USD残差RL)が混在し、「RLが優れている」とは
  言えない状態
- 次に有望な方向は本レポートの「効かなかったもの」を踏まえると、(a) 独立ユニバースの
  さらなる拡大(G10以外・異なる資産クラス)による統計的検出力の強化、(b) CFTC建玉など
  ポジショニング系データ(未実装・カバレッジ課題あり)、(c) RLをユニバース非依存にする
  ための特徴量正規化・マルチユニバース同時学習、が挙げられる
