# 03. ルールベース ceiling 診断とクロスセクション・リバーサルの発見

期間: 2026-07-02〜03

## 方法: ceiling 診断

RL の学習不良と「そもそもシグナルが無い」を区別するため、**スクリプト化したルール
ポリシーを env の実コストモデルに通し、walk-forward(評価年 2019〜2025)でグロス/ネットを
測る**診断を導入した(学習不要、数分で完了)。実装は `walk_eval_range` + `build_single_env`
に決定論的ルール関数を差すだけ(scratchpad の `tsmom_ceiling.py` / `xs_ceiling*.py` 参照)。

**原則: 新しい特徴量空間・ペア集合では、ルール ceiling のグロスが正であることを確認して
から RL を投入する。**

## 結果1: 2ペア時間足には alpha が無い

JPY/USD + JPY/EUR 時間足(k=24)で古典的 TSMOM ルール(sign/tanh of mom168/mom720、
ブレンド)を診断: **グロス最良でも +1.2%/年、ネットは全て負**。ラウンド0〜6 の RL が
グロス ≈ 0 に張り付いていたのは学習の失敗ではなく、**この空間に取れるエッジが存在しない**
ためだった。

## 結果2: 7 JPYペアのクロスセクションにはリバーサル構造が実在する

ユニバースを 7 JPYペア(USD, EUR, GBP, AUD, CHF, CAD, NZD)の日足に拡張
(`data/jpy_7pairs_1d.parquet`、yfinance 2015+。時間足は Dukascopy の IP ブロックにより保留)。

- **クロスセクション・モメンタム**(上位2ロング/下位2ショート)は全ホライズン
  (mom24/72/168/720)で**グロス負**(−2.3〜−3.1%/年)。
- 符号を反転した**リバーサル**は全ホライズンで**グロス正**(+1.4〜+4.2%/年)—
  8ルール中8ルールで符号が一致する系統的構造。JPYクロスは相対的に平均回帰する。

## ルールベンチマーク(RL が超えるべき基準)

| ルール | ネット/年 | グロス/年 | Sharpe | 勝ち年 |
|---|---|---|---|---|
| 1ヶ月リバーサル top2、毎日 | +1.0% | +4.2% | +0.23 | 5/7 |
| 同、10日ごと | +1.2% | +4.1% | +0.35 | 5/7 |
| **同、ヒステリシス付き、5日ごと** | **+1.3%** | **+4.2%** | **+0.29** | **5/7** |
| 滑らか重み(z比例) | +0.3% | +2.5% | +0.09 | 4/7 |

- alpha はランクの**端**に集中(滑らか重みはコストは減るがグロスも減る)。
- コストがグロスの約7割を消費 → **「エッジがコストを超える時だけ取引する」タイミング
  最適化が主要な改善余地** = コスト込み報酬の RL に構造的に向いた問題設定。

## 留意事項

- 約9種のルールを試した上での最良値であり、軽度の選択バイアスを含む(信頼の根拠は
  符号の系統性)。
- 日足ユニバースは1フォールドあたり訓練 1,000〜2,400 バーと小さい。時間足 7ペア
  (バー数24倍)が取得でき次第、同じ診断を再実行する価値がある。
