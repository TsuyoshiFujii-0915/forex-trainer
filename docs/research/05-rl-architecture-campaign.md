# 05. RL 本体の改善キャンペーン(ラウンド15〜17、二時代プロトコル)

期間: 2026-07-05〜10 / 目標: ルール床なしの純RLで walk-forward ネット +7%/年、
両時代(2009〜2018 / 2019〜2025)で正

## プロトコル

- 開発フォールド: 評価年 2009〜2025 の17フォールド、train は expanding window
  (キャッシュ実始点 2005-07-19 — 後述のデータ注記参照)、val 直前6ヶ月
- 封印: 2006〜2008 は最終設計の一発確認専用(結果的に 2007〜2008 の2フォールド)
- `residual: none`(ルール床なし)、signed 資金調達、9ペア日足、xs+キャリー特徴量

## 探索結果

| ラウンド | 変種 | 結果(dev) | 判定 |
|---|---|---|---|
| 15 | PPO + MLP(基準) | 全体 −1.1%/年 | 不合格 |
| 15 | PPO + xattention(ペア間attention、新実装) | −4.3%/年 | 不合格 |
| 16 | 正則化PPO(lr 1e-4, ent 0.01, 小型) | スクリーン −4.7% | 落選 |
| 16 | **long: n_steps 1024 / batch 1024 / 300k steps** | スクリーン **+6.0%** | **本検証へ** |
| 16 | RecurrentPPO | スクリーン −9.4% | 落選 |
| 16 | TQC(off-policy) | +0.2%(縮退・ほぼ無取引) | 落選 |
| 17 | long + xattention | スクリーン +4.7% | long 未満 |
| 17 | n_steps 2048 / 500k | スクリーン +2.5% | 飽和 |
| 17 | long の ens5 | 全体 +4.3% | ens3 未満 |

**効いた唯一のダイヤルは「ロールアウト長 n_steps 256→1024(+学習 300k)」**。
アドバンテージ推定の分散低減が本質と推定。アーキテクチャ(ペア間attention含む)、
再帰、オフポリシー、正則化はすべて負けた。

## 最終設計と成績: `longf ens3`

PPO + MLP、n_steps 1024 / batch 1024 / lr 3e-4 / gamma 0.999 / ent 0.001、
300k steps、3シード行動平均(configs/wf_r16_long_full)。

- **dev 17フォールド: ネット +4.7%/年、Sharpe 0.46、12/17年、平均レバレッジ 1.94**
  - era 2009〜2018: **+6.7%/年(7/10)** / era 2019〜2025: **+1.8%/年(5/7)** —
    **両時代で正(合格基準クリア)**
  - 弱点: 2009 −32.5%、2015 −24〜35% のテール(レジーム断絶年)
- **封印確認(2007〜2008、一発)**: 2007 −5.4% / 2008 +21.0%、平均 +7.8%。
  ただし 2008 は1シードの +50% が支配(シード間 +1.3/+50.2/−3.0)で、封印フォールドの
  訓練データは1〜3年しかなく検出力が低い。「弱く整合的、ただし証拠力は限定的」が誠実な評価
- **目標 +7%/年 に対して: 未達(+4.7%)**。ただしルール床なしの純RLとして、
  一般化するルールの誠実な期待値(21年で +2.6%/年)を上回った

## データ注記(重要)

- yfinance の NOK/SEK 日足は **2005-07-19 開始**。9ペアの inner join により全キャッシュの
  実始点は同日(メタデータの宣言範囲 2003-01 は取得リクエスト値)。封印 2006 フォールドは
  訓練データ不在で実行不可能。21年マップの「2005年」は実質 H2 のみ
- 旧 yfinance データのスパイク型不良プリントは修復済み(04 参照)。この監査は
  リバーサル系戦略の必須前提
