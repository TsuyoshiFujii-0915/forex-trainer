# 0001. 学習リポジトリの分離と forex-env-v3 へのパス依存

## Status

accepted

## Context

環境(forex-env-v3)は検証済みで安定しており、変更には ADR とテストの規律を課している。一方、エージェント学習は高速な試行錯誤の場であり、両者を同一リポジトリに置くと環境の信頼性が実験コードの変化に巻き込まれる。

## Decision

学習・実験コードを独立リポジトリ forex-trainer とし、forex-env-v3 には uv のパス依存(`[tool.uv.sources]` で `../forex-env-v3`、editable)としてのみ依存する。2つのリポジトリは隣同士に配置することを唯一の配置規約とする。Docker ビルドは親ディレクトリをコンテキストにして両リポジトリを取り込む。

- 依存方向は trainer → env の一方向のみ。trainer から env の内部実装(プライベート関数)には依存しない
- 環境側に欲しい機能が生じた場合は、trainer 側で回避策を実装せず、forex-env-v3 に ADR を起こして追加する(例: ADR-0007 の file プロバイダー)

## Consequences

- 環境のテスト・検証履歴が実験コードと独立に保たれる
- クローン時は2リポジトリを並べて配置する必要がある(uv.lock は相対パスを記録する)
- 環境のAPI変更時は trainer 側の追従が必要(editable 依存のため開発中は即時反映される)
