# Title

0031. 開発期間の採否と未使用期間の独立確認を分離する

## Status

accepted

## Context

Issue #20は、同じ評価期間への設計反復と、過去の確認期間の再利用を防ぐ契約を必要とする。
#15のlearnabilityと#16/#19のportfolio分類は2009〜2025のdevelopment evidenceであり、
事前に基準を置いたことだけでは独立確認にならない。2007〜2008、2026H1にも既知の利用がある。

## Decision

出典付き期間利用台帳を未使用認定の必要条件とする。未確認は未使用に読み替えず、使用済み期間を
再封印しない。2009〜2025をdevelopment foldsと固定する。過去成果物の分類を変更せず、
今後の採否はネット正、canonical置換、RL追加価値を別々に判定する。

[次期protocol](../research/14-research-and-forward-protocol.md)で採否・停止・条件分岐と試行範囲を
固定し、独立確認は設計固定後の将来期間に限定する。外部入力・時刻・成果物identityが未確定なら
開始不可とする。候補日程を逃した場合も後から開始日を遡らせない。
開発foldの既存集計はADR-0012〜0019、#15/#16/#19の分類はADR-0028〜0030を維持する。
新たな独立確認の統計設計がない限り、短期の前向き運用結果による分類昇格を認めない。

## Consequences

- #19を本Issue待ちで止めず、その既存測定契約による診断を次の分岐の入力にできる。
- 既存のtrial_countは対象範囲ごとに保存し、全研究の独立試行数や補正済み有意性を捏造しない。
- 次期契約は開始条件をレビュー可能にする。将来の観測完了はIssue #20の完了条件に含まない。
