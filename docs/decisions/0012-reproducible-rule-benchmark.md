# 0012. 価格リバーサル基準ルールをコミット済みCLIで再現する

## Status

accepted

## Context

研究レポートはクロスセクション価格リバーサルをRLの比較基準としているが、計算に使った
診断スクリプトはgit管理外の`scratchpad`にあり、現在のworkspaceには存在しない。会計式や
キャッシュ契約を変更した際に、基準値を同じ公開環境経路で再計算できなければ、RLとの差を
現行仕様で検証できない。

## Decision

`forex-rule-eval`をコミット済みCLIとして提供する。実験YAMLの評価区間と公開環境構築経路を
使用し、指定特徴量の下位`top_k`をロング、上位`top_k`をショートする価格リバーサルを、
残差行動ラッパーの残差をゼロに固定して評価する。出力JSONにはルール契約、必須パラメータ、
設定ごとの全指標、全foldの平均log returnから算出した集約returnを保存する。

特徴量のペア別window正規化は横断順位の意味を変えるため拒否する。`top_k`のlong/short集合が
重なる設定も拒否する。設定、特徴量、サイズはすべてCLIで明示し、暗黙の既定値は持たない。

## Consequences

- 会計・コスト・Carry・データproviderをRL評価と同じ実装で通した基準値を再生成できる
- 一時スクリプトに依存せず、研究文書のルール値をレビュー可能な成果物へ結び付けられる
- 本CLIは固定方策の評価であり、ルール探索やパラメータ選択は行わない
