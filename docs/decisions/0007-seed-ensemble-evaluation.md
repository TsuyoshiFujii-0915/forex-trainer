# 0007. シードアンサンブルによる評価(行動平均)

## Status

accepted

## Context

長期データでの k24_mom 実験(ラウンド3)は、5シード中2つが明確なプラス(Sharpe +1.3〜+1.5)を出す一方で3つがマイナスであり、単一シードの成績はシード選択という偶然に大きく依存する。深層RLの標準的な分散低減手法は独立に学習した複数モデルのアンサンブルであり、本タスクの行動空間(ペアごとの目標ウェイト、[-1,1] の連続値)は行動の算術平均がそのまま有効な行動になるため、行動平均アンサンブルが自然に定義できる。

## Decision

`forex-ensemble-eval` CLI を追加する。複数の学習済み run ディレクトリを受け取り、次のプロトコルで評価する:

- 全メンバーの解決済み評価環境(`env_eval.yaml`)と `decision_interval` が完全に一致することを検証し、不一致は即エラーとする
- 共有の評価環境を1回だけ歩き、各決定で全メンバーの決定論的行動(目標ウェイト)の算術平均を環境に転送する
- 指標は forex-eval と同一の `compute_metrics` で計算する
- 成果物は `runs/<実験名>_ens<N>/<UTCタイムスタンプ>/` に封入する: `metrics.json`、`equity_curve.csv`、メンバー run のパスと git SHA を記録した `ensemble.json`、共有 `env_eval.yaml`

アンサンブルは評価時のみの合成であり、学習プロトコル(ADR-0005)には手を加えない。

## Consequences

- シード起因の分散が直接低減され、「どのシードを引いたか」への依存が減る
- 推論コストはメンバー数に比例して増える(実運用時も N モデルの推論が必要)
- メンバー間で行動が打ち消し合うとポジションが縮小する(ネットで見送りに相当)— これは合議制の意図した挙動
- forex-compare は ensemble run の metrics.json も同じ契約で集計できる
