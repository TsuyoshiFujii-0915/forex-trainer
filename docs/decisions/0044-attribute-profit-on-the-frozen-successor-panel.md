# Title

0044. 固定した後継区間で利益帰属と2対照を評価する

## Status

accepted

## Context

Issue #39は出口Bとして8全範囲・9部分年の連続区間を固定し、#29後継は153口座を完走した。
2026-09-22の利用者指示は#39を踏まえた#30の評価継続である。旧通年の不足45セルは解消していない。

## Decision

`issue30-contiguous-attribution-v1`として#29後継のsealed F0全51口座を採用する。
ADR-0039の会計・2対照・照合・統計を再利用し、85口座を新しい比較契約で評価する。
既存通年validatorや旧attemptは変更しない。全51元方策を同じruntimeでreplayし、
親の全trace・metrics・時刻・市場値の完全一致を確認してから同runtimeの対照と比較する。

constantは元訓練cache・範囲の既存warmup後の全decisionを使う。
訓練入力に残る欠損横断、UTC経過時間によるcarry、2005年以前の履歴不足を明示的に継承する。
訓練gapを削除・補間せず、今回の連続評価区間の規則を過去訓練に遡及適用しない。
平均は訓練内の実効weightから求め、terminal時には部分平均を採用せず未完了とする。
projectedは自身の口座状態で凍結PPOを再推論する。いずれもサイズの事後調整はしない。

全85口座完走時だけ17区間等重み、era 2009–2018 / 2019–2025、既存10,000 IID/
3-fold circular moving-block・seed16・95%区間・全LOO・最大寄与を出力する。
年率寄与は各区間の実経過時間を使い、期間収益・coverage・volatilityも併記する。
これはcoverage選択に条件付けた記述であり、17通年推定や連続口座CAGRではない。
主要源泉と次期学習問題は数値を研究ノートで解釈し、事後的な閾値で自動分類しない。

## Consequences

- 旧45セルの不足と後継85口座の完了を別々に記録できる。
- 訓練由来対照のgap仮定、共通投影のリスク差、入力vintageの限界は残る。
- 新規学習、追加対照、特徴量探索、旧収益性の再認定は行わない。
