# Title

0043. Issue #39の固定連続区間で後継の費用評価を行う

## Status

accepted

## Context

Issue #39は回復を出口Bで終了し、損益を使わずに17の連続評価区間を固定した。
2026-09-22の利用者指示はこの結果を踏まえたIssue #29の評価継続である。
8区間は全期待barを含むが9区間は部分年であり、旧通年契約の完了を主張できない。

## Decision

`issue29-contiguous-cost-v1`として固定snapshotを採用する。旧17通年attemptは未完了のまま保全する。
入力や範囲の再選択、新規取得、学習は行わず、既存の凍結3方策×F0/F1/F2の153口座を
同じruntimeで再実行する。既存cost campaignの口座実行、会計照合、費用感度、統計を再利用し、
旧validator、約定・費用・報酬、generic comparisonは変更しない。

主集計は新しい17区間の等重み平均（年率net/gross）、eraは元fold年の2009–2018 / 2019–2025。
年率化は各区間の実経過秒を使用し、区間収益、期間長、除外時刻を併記する。
bootstrapは既存10,000 IID / 3-fold circular moving-block、seed16、95%区間、全LOO・最大fold寄与。
方策間は同scenario内の対応比較、費用感度は同方策・同時刻で費用だけの差を照合する。
絶対net/grossの区間も既存paired_evidenceとzero基準で算出する。
これらはcoverageで選ばれた固定区間に条件付けた記述であり、欠損時期を含む17通年母集団の推定、
未使用期間の独立確認、連続運用CAGRではない。全153セル完走までは集計を出さない。

新親sealから#30へF0のstep/pair traceを渡す。#30の帰属・2対照は本作業では実行しない。
旧#16との違いは個別の記述に限定し、期間効果の因果推定や新旧混合のpaired検定をしない。
方策の整理は同じ既存開発用ルールを使用し、絶対/対応区間、era、LOO、弱いfoldと併記する。
旧#16分類・canonical置換・独立収益性の認定は変更しない。

## Consequences

- 旧不足81セルを成功へ書き換えず、後継範囲の153口座を最後まで評価できる。
- 不等期間の年率化やcoverage選択の影響を明示した基準線を次期設計へ渡せる。
- 別の取得や新しいモデルの学習は、別の有限予算・登録を要する。
